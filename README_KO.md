# Dreamine.Gem.Abstractions

Dreamine의 공급자 중립 GEM 계약과 불변 도메인 모델입니다.

[➡️ English Version](https://github.com/CodeMaru-Dreamine/Dreamine.Gem.Abstractions/blob/main/README.md)

SECS 메시지 전송 경계, 형식화된 Variable, Constant, Event/Report, Alarm,
Remote Command, Process Program, Clock, Spool 서비스 계약, 상태 Enum 및 불변
정의를 제공합니다. 구체 HSMS 구현이 아닌 `Dreamine.Secs.Abstractions`에만
의존합니다.

이 계약 자체는 구현체가 GEM 메시지 시나리오 전체를 지원하거나 특정 SEMI
Revision을 준수한다는 의미가 아닙니다.
